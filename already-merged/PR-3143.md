## AI Summary
- **What it does**: Adds an optional `date_local` field to the slim email message envelope in the Gmail post-process reshaper. `format_email_local_time()` converts UTC timestamps (RFC 3339 or RFC 2822) to the host's local timezone via `chrono::Local`, formatted as `%Y-%m-%d %I:%M %p %:z`. The raw `date` field is always preserved. Addresses issue #3128 where the agent presented UTC timestamps to users.
- **Breaking risk**: Zero — additive field only, no existing callers affected, absence of `date_local` on UTC hosts is explicitly valid.
- **Security risk**: Zero — timestamp formatting, no user-input injection surfaces, no secrets.
- **Bottom line**: Safe to merge once CI passes.

## UI Impact

- **User flow**: Unchanged at UI level; agent can now present local timestamps without manual UTC arithmetic.

- **Risk**: None
- **Recommendation**: No design review needed.
