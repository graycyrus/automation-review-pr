## AI Summary
**What it does**: Introduces a first-class `task_sources` domain that periodically pulls work items from external tools (GitHub issues, Notion tasks, Linear issues, ClickUp tasks), applies deterministic urgency enrichment, deduplicates via SHA-256 content hash, and routes new items onto the agent's todo board. Proactive sources additionally dispatch a triage turn through the existing Composio webhook path, gated by the scheduler.

**Breaking risk**: Zero. Entirely additive — new SQLite store, new config block with backward-compatible defaults, new RPC surface, new event variants. No existing APIs modified except adding a default-Err trait method.

**Security risk**: Low. External task titles/bodies flow into AI triage prompts (intentional by design, consistent with existing Composio webhook handling). No secrets stored. Assignee resolution is fail-closed. URLs from external sources stored as text only. No injection surfaces.

**Bottom line**: Safe to merge once CI is green and the bus.rs blocking-fetch issue is resolved.
