## AI Summary

**What it does**: Reorders the `is_session_expired_message` check in `expected_error_kind()` to run before `is_embedding_backend_auth_failure`. This fixes a regression introduced by PR #2830 which matched the same parenthesised embedding 401 "Invalid token" wire shape as #2786, causing conflicting test assertions and a red Rust CI on main.

**Breaking risk**: Low. Re-buckets one error shape from `BackendUserError` to `SessionExpired`. Both are Sentry-suppressed; the behavioral difference is the downstream re-auth signal. Bare-status and BYO-key 401s are unchanged.

**Security risk**: Zero. Pure classifier reorder in an error categorization function — no auth, secrets, injection, or network surfaces touched.

**Bottom line**: Safe to merge.
