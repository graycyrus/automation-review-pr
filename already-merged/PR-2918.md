## AI Summary
- **What it does**: Extends `ConversationMessage::AssistantToolCalls` with an optional `reasoning_content` field (serde-defaulted for backward compat), captures it during agent turn execution, and includes it in the serialized provider payload via `NativeToolDispatcher`. Fixes DeepSeek 400 errors (TAURI-RUST-4K9/4KA) caused by thinking-mode reasoning content being dropped between tool-call turns.
- **Breaking risk**: Zero. Schema change is backward-compatible — field is optional with `#[serde(default, skip_serializing_if = "Option::is_none")]`. All existing test fixtures updated to `reasoning_content: None`.
- **Security risk**: Zero. No new permissions, network surfaces, or data exposure.
- **Bottom line**: Safe to merge once CI is green.
