## AI Summary

**What it does**: Adds a "Calibration" tab to the Intelligence page where users log predictions with a subjective confidence level, later resolve them true/false, and see Brier score, 10-bin calibration curve, Murphy decomposition, and cumulative trend. Persists as a single JSON blob via existing memory file RPCs — zero new core surface.

**Breaking risk**: Low. No changes to shared Rust types, existing state shape, or exported APIs. New frontend files only; the tab is additive.

**Security risk**: Low. User-supplied strings (statement, category) rendered via React (XSS-safe). The parser validates the on-disk blob robustly with `parsePredictionRecords`. No eval, no injection surfaces; `resolveBy` is converted to epoch seconds only.

**Bottom line**: Safe to merge once CI goes green.
