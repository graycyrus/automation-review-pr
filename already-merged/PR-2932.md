## AI Summary
**What it does**: Adds a forgetting-curve decay model applied to the assistant's stored knowledge graph facts. Each (subject, predicate, object) triple gets a recall score based on age and evidence count; the UI shows fresh/fading/stale counts and a re-confirm queue of the most stale facts. Pure read-only — nothing is persisted and the engine is fully deterministic (clock injected by caller).

**Breaking risk**: Zero — purely additive. No existing APIs, types, DB schemas, or exported functions changed. One type union extended.

**Security risk**: Zero — read-only feature, uses already-shipped RPC wrappers, no user input eval, no new data persistence, no secrets.

**Bottom line**: Safe to merge.
