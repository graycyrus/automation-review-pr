## AI Summary
**What it does**: Introduces multi-agent personalities — each `AgentProfile` can now have its own identity (SOUL.md), memory directory (isolated SQLite DB), voice, and composio integration allowlist. A new `delegate_to_personality` tool lets the master agent hand off tasks to personality-scoped sub-agents. Thread binding lets conversations stay attached to a specific personality. Fully backwards compatible — existing single-agent setups see no change.

**Breaking risk**: Low. All new fields are optional with sensible defaults. Existing `UnifiedMemory::new()` delegates to the new `new_with_memory_dir("memory", ...)`. TS interface changes are additive. Default profile auto-promoted to `is_master: true` on load.

**Security risk**: Low. Path traversal vectors fixed — `soul_md_path` and `memory_subdir` both validate components before join.

**Bottom line**: Safe to merge once CI is green. All findings addressed.
