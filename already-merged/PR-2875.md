## AI Summary

**What it does**: Adds a full user-facing surface for the skills runtime introduced in #2707 — a scheduled-skills dashboard (Runners sub-tab), a `/skills/run` runner page, a `/skills/new` authoring page with an `[[inputs]]` editor, a `[github]` preflight gate for skills that need GitHub access, and a hard switch of all GitHub I/O from `gh` CLI to `composio_execute`. Also migrates DevWorkflowPanel from localStorage config to live cron RPC state.

**Breaking risk**: Low. No public API changes, no DB schema changes, no config format breaks. Codepath changes are additive (new RPC methods, new pages, new agent tools). The composio-only GitHub I/O shift changes agent behavior at runtime but not at the wire level.

**Security risk**: Medium. One finding: `OPENHUMAN_CEF_NO_SANDBOX` env var disables the CEF browser sandbox but is not guarded to debug/dev builds — ships in release binaries. Chrome's sandbox is a meaningful security boundary.

**Bottom line**: Not safe to merge as-is — CI is failing and the sandbox bypass needs a compile-time gate before shipping in release.
