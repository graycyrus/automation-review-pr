## AI Summary
- **What it does**: Adds a "Beliefs" tab to the Intelligence page that visualizes how the agent's beliefs about the user have changed over time. Surfaces temporal contradictions in the knowledge graph (subject/predicate/object + updatedAt + evidenceCount), picks a current best belief via a recency × log(evidence) scoring formula (180-day half-life), classifies each revision (reinforced/refined/superseded/contradicted), and lets users request LLM explanations and persist corrections via existing RPCs.
- **Breaking risk**: Zero. All changes are purely additive — new files plus a new tab entry in Intelligence.tsx. No existing APIs, types, shared state, or RPC methods modified.
- **Security risk**: Low. One PII concern: `saveCorrection` debug-logs `params.correctObject` (flagged by CodeRabbit). LLM prompt in `buildExplanationPrompt` contains user belief data but is user-triggered and intentional. No new injection surfaces, no auth bypass, no new network endpoints.
- **Bottom line**: Safe to merge once CodeRabbit's three issues are addressed and CI is fully green.
