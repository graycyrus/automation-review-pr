## AI Summary
- **What it does**: Migrates ClickUp Composio task sync off the legacy `persist_single_item` / `memory_docs` path onto the `memory_tree` document ingest pipeline (matching the Linear/Notion migrations), so synced ClickUp tasks become retrievable via `memory.search`, `tree.read_chunk`, and agent recall. Also adds macOS subprocess timeout protection for all three accessibility subprocess calls (`command_output_with_timeout`), enriches the GitHub reader with issue/PR comments and participant lists, switches `ToolMemoryRule::generate_id` to a PII-safe a-p alphabetic encoding, and fixes several test-infra races/flakes.
- **Breaking risk**: Low. The ingest migration changes where ClickUp data lands (from `memory_docs` to `mem_tree_chunks`), so existing synced tasks won't appear in new retrieval until re-synced. No API or config schema changes.
- **Security risk**: Zero. No auth, secrets, or injection surfaces touched. The timeout helper correctly kills+reaps child processes.
- **Bottom line**: Safe to merge — pending CI green.
