## AI Summary

**What it does**: Adds a unified memory sources registry that lets users configure multiple data connectors (Composio integrations, local folders, GitHub repos, RSS feeds, web pages, Twitter queries) as memory inputs. Replaces the Composio-only sync panel with a single "Memory Sources" UI panel, adds CRUD RPCs for managing sources, and wires per-source sync and status tracking (+6507/-910 lines across 48 files).

**Breaking risk**: Low. New `[[memory_sources]]` TOML field uses `#[serde(default)]` so existing configs load unchanged. The Composio sync engine is untouched. `list_sync_targets` fallback preserves legacy behavior.

**Security risk**: Medium. The web_page reader has a scheme-only SSRF check (no internal IP filtering — CodeRabbit critical). The folder reader's `read_item` has a TOCTOU between the canonicalize check and the actual file read.

**Bottom line**: Not safe to merge yet — TOCTOU in folder.rs and missing persistent sync error state need resolution.
