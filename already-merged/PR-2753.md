## AI Summary

**What it does**: Adds Querit as a new web search engine provider alongside Managed, Parallel, Brave, Seltz, and SearXNG. Users configure a Querit API key in Settings > Search, and when Querit is selected, the core calls the Querit POST API for web search with support for site, time range, country, and language filters. Includes full i18n support across 10 languages and Tauri settings UI integration.

**Breaking risk**: Zero. New optional search provider with no changes to existing search engine paths or public APIs.

**Security risk**: Zero (fully resolved). All error paths hardened:
1. ✅ Querit API key included in decrypt_config_secrets + encrypt_config_secrets (load.rs), mirroring Parallel/Brave pattern
2. ✅ HTTP error responses: Only status code in error messages, never body
3. ✅ Application-level errors: Only error_code in error messages, never error_msg
4. ✅ Comprehensive negative tests verify no sensitive data leaks (test_execute_non_success_status_does_not_expose_response_body, test_execute_app_error_does_not_expose_error_msg)

**Bottom line**: Safe to merge — code quality excellent, all security hardened, CodeRabbit approved. Ready for approval once CI completes.
