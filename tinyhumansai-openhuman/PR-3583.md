#### Findings
- [major] `app/src/components/intelligence/IntelligenceTeamsTab.tsx:144` — `refresh()` doesn't call `setError(null)` before delegating to `fetchDetail`. If the initial detail fetch fails (setting `error`), clicking retry calls `fetchDetail` which on success sets `view`/`messages` but never clears `error`. The error UI persists and the user cannot recover without navigating away. Fix: add `setError(null)` at the top of `refresh` (or at the start of `fetchDetail`). `fetchTeams` already has this pattern — `fetchDetail` doesn't.
