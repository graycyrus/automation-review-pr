## AI Summary
- **What it does**: Adds a 5-minute safety ceiling (`TTS_MAX_PLAYBACK_MS`) to auto-stop runaway TTS playback so the mascot can't get permanently stuck in `speaking` pose. Adds `retryCount` UI state to `MicComposer` so users see "Retrying… (1 of 2)" instead of a generic spinner during exponential-backoff STT retries. Adds session-correlated `[session:N]` prefixes and lifecycle logging throughout audioPlayer and MicComposer for grepping voice session traces.
- **Breaking risk**: Low — `playBase64Audio` gains an optional third parameter with default `{}`, all existing callers are unaffected. Exports `TTS_MAX_PLAYBACK_MS` and `STT_MAX_RETRIES` as new constants (additive).
- **Security risk**: Zero — no auth, no user data surfaces, no new network paths.
- **Bottom line**: Safe to merge once CI is green.
