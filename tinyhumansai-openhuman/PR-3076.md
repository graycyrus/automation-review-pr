## AI Summary

- **What it does**: Overhauls the memory pipeline to classify embedding/extraction failures as typed transient vs unrecoverable errors, adds BYO OpenAI/custom embeddings support to the memory-tree path, surfaces a `degraded` pipeline status with actionable remediation banners, adds a one-shot `memory_doctor` RPC+agent tool, enables cloud summarizer fallback for Build Summary Trees, and fixes the vault-ledger dead-lock preventing re-ingest after memory reset.
- **Breaking risk**: Low. Additive SQLite migration (nullable columns), additive RPC fields with serde defaults, additive TypeScript types. No schema removals. The cloud summarizer fallback is a behavioral change but not an API break.
- **Security risk**: Zero. No new auth flows, no new network surfaces, no secrets. Credential resolution reuses existing factory (`create_embedding_provider_with_credentials`).
- **Bottom line**: Safe to merge structurally, but the privacy regression (cloud summarizer without UI notice) and CI failures should be resolved first.

## UI Impact

- **Visual change**: Intelligence panel gains amber "Degraded" pill + actionable remediation banner with per-cause i18n text and recall/structure badges. Extraction coverage % shown below status tiles.
- **User flow**: Unchanged for healthy setups. Degraded setups now see an explicit amber warning instead of a misleading "Running" state.
- **Affected surfaces**: `MemoryTreeStatusPanel` only (no shared components modified).
- **Risk**: Low — additive UI elements, no layout changes to existing flows.
- **Recommendation**: Approve UI as-is once CI is green.
