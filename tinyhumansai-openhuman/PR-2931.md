## AI Summary
- **What it does**: Adds a read-only "Centrality" tab to the Intelligence page that runs PageRank + degree centrality + connected-component analysis over the memory knowledge graph. Surfaces hub entities and bridge/connector entities that a raw frequency sort cannot detect. Pure deterministic engine; reuses existing RPC wrappers; nothing persisted.
- **Breaking risk**: Zero. No shared types changed, no exported API surface modified, no Redux state touched, no DB schema changed. New tab wired via a one-line union extension to `IntelligenceTab`.
- **Security risk**: Zero. Read-only, no user input unsanitized for display beyond entity names (already stored in the graph), no new IPC surface, no secrets.
- **Bottom line**: Safe to merge — clean additive feature, well-tested, zero side effects.
