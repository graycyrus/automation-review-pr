## AI Summary
- **What it does**: Introduces `prime_index_if_cold()` to move the cold inverted-index rebuild outside `CONVERSATION_STORE_LOCK`, preventing the first `search_cross_thread_messages` call from blocking concurrent `append_message`/`get_messages` for multi-seconds on large workspaces. Uses `thread_index_unlocked()` (header-only) under the lock to snapshot thread IDs, then reads per-thread JSONL lock-free. Adds three regression tests covering both modern and legacy (pre-Stats) workspaces.
- **Breaking risk**: Low — changes are internal to the memory_conversations module; no public API, type, or schema changes.
- **Security risk**: Zero — pure internal concurrency refactor; no auth, IO surface, or network changes.
- **Bottom line**: Safe to merge — all prior findings addressed, design is correct.
