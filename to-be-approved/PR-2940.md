## AI Summary
- **What it does**: Fixes two bugs in the Local AI pipeline. First, `local_ai_summarize` was routed through the gated `summarize` path so a held scheduler permit caused silent drops; the fix routes it through `summarize_interactive` which bypasses the gate. Second, Ollama diagnostics incorrectly reported "all checks passed" even when the runner could not execute models; the fix adds an `ollama_runner_ok_at` probe and surfaces a specific issue message when the runner is reachable but broken.
- **Breaking risk**: Zero. TypeScript interface change is additive (optional field). Rust changes add a new method and reroute one RPC call.
- **Security risk**: Zero. No new input surfaces, no secrets, no injection vectors. Diagnostic probe uses internal HTTP client to configured base URL.
- **Bottom line**: Safe to merge.
