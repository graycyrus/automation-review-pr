## AI Summary

**What it does**: Reduces debug symbol size in the `rust-e2e-linux` test build by setting `CARGO_PROFILE_DEV_DEBUG` and `CARGO_PROFILE_TEST_DEBUG` to `line-tables-only` instead of full DWARF. This shrinks `target/debug` enough to fit on the runner disk while preserving panic locations (from `#[track_caller]`, not DWARF) and backtrace file:line data (via `RUST_BACKTRACE=1` + retained line tables). Only debugger-only symbol inspection is lost, which CI never uses.

**Breaking risk**: Zero — CI-only, no product/API changes.

**Security risk**: Zero — environment variable tweak for build process.
