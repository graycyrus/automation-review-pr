## AI Summary
- **What it does**: Wraps `OpenAiEmbedding::embed` and `CohereEmbedding::embed` in a retry loop handling 429/503 responses with Retry-After header awareness and exponential fallback (1s → 2s → 4s, capped at 30s, max 3 retries). Introduces a new `retry_after.rs` helper module. Also adds a `TransientUpstreamHttp` classification test to pin the canonical 429 error message shapes.
- **Breaking risk**: Low. Internal implementation change only; no exported API changes, no schema changes, no config format changes. Voyage inherits the fix via OpenAiEmbedding.
- **Security risk**: Zero. No auth surface changes, no new external inputs, no injection surfaces.
- **Bottom line**: Safe to merge — correct implementation addressing the project's highest-volume Sentry issue.
