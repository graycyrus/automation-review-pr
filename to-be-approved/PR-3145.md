## AI Summary
- **What it does**: Raises the desktop OAuth loopback listener's hard-kill deadline from 60s to 300s, and raises the JS button loading-state reset timer from 90s to 300s to match. Fixes silent auth failures for users with slow interactive sign-ins (2FA, first-time consent, password managers) where the listener was dying mid-flow.
- **Breaking risk**: Zero — constants are module-private; the Rust shell already honours the JS-supplied `timeoutSecs`; no public API, type, or schema changes.
- **Security risk**: Zero — loopback-only listener, per-click nonce, single-use; extending the window by 4 minutes does not introduce meaningful new attack surface given the existing constraints.
- **Bottom line**: Safe to merge — minimal, well-justified timeout constant change with matching test updates.
