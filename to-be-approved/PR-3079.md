## AI Summary
- **What it does**: Replaces the subconscious task/escalation/execution pipeline with a simpler agent-per-tick model. Each tick runs a single agent call, parses structured "thoughts" (reflections) from JSON output, creates a conversation thread, and stores the reflections with a `thread_id` so users can navigate to the agent's reasoning from the UI.
- **Breaking risk**: Medium — 8 RPC endpoints removed (`tasks_*`, `log_list`, `escalations_*`). External consumers of those RPCs will get "unknown function" errors. Legacy DDL retained so existing DBs don't break. Documented in PR.
- **Security risk**: Zero — no auth changes, no new network surfaces, no secrets handling. Thread creation uses internal `ensure_thread` API.
- **Bottom line**: Safe to merge — well-scoped refactor, additive DB migration, breaking RPC change is intentional and documented.

## UI Impact
- **Visual change**: Intelligence > Subconscious tab loses task management UI, escalation approval cards, and activity log. Gains only a "View" button on reflection cards that navigates to the agent's conversation thread.
- **User flow**: Simpler — users can no longer add/toggle/remove tasks or approve escalations from the UI. Reflection "View" button is new navigation entry point.
- **Affected surfaces**: `IntelligenceSubconsciousTab`, `SubconsciousReflectionCards`, `Intelligence.tsx`
- **Risk**: Low — the removed features (task management, escalation approval) are being replaced by the agent model, not just deleted.
- **Recommendation**: Approve as-is once CI is green; no design review needed (simplified surface).
